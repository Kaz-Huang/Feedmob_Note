2. In `/etc/caddy/Caddyfile`, change only `workweave.techmob.net`'s upstream from `127.0.0.1:3004` to `127.0.0.1:3003`. The prior config is available in the backup for comparison.
3. Validate, restart Caddy, and verify the site before stopping the current container:

```sh
sudo caddy validate --config /etc/caddy/Caddyfile --adapter caddyfile
sudo systemctl restart caddy
docker stop workweave
docker rename workweave workweave-failed-20261013-columns
docker rename workweave-rollback-20261013-notion-ui workweave
```

The shared Caddy restart briefly interrupts all sites on the host. Preserve later changes to other domains when editing the proxy configuration.
